# 1면 헤드라인 손보기

이 폴더는 비어 있어도 됩니다.

1면 머릿기사는 어느 신문사도 공개 데이터로 주지 않아서, 각 사 종합 피드에서
새벽에 올라온 첫 기사를 후보로 세웁니다(지면에 "추정" 표시가 붙습니다).

특정 날짜만 손으로 바로잡고 싶으면 `2026-07-28.json` 같은 이름으로 아래 형식의
파일을 만들어 두면 그날은 이 내용이 우선합니다.

```json
[
  {"press": "경향신문(서울)", "title": "정유사들, 전쟁 틈타 14조 담합·갑질", "url": "https://..."},
  {"press": "조선일보(서울)", "title": "...", "url": "https://..."}
]
```

적은 신문사만 덮어써도 되고, 나머지는 자동 추정값이 그대로 남습니다.
